## Summary

- **Effects that exist:**
  - Per-track DIST and an INSERT (SOFT/HARD/FOLD/FUZZ drive, CRUSH, PHASR, FLANG, CHOR).
  - Three mono send buses: CHORUS, a tempo-synced DELAY, and REVERB (ROOM Freeverb-like, SPRING with a dispersive allpass loop, HALL as an 8-line FDN at half rate, stereo).
  - A performance "FX layer" on the master: REPEAT/REVERSE/TAPE STOP/FREEZE, an OCT UP/DN harmonizer, LPF/HPF ZDF SVF sweeps, CRUSH, a stereo FLANGER, and a stereo 4-stage PHASER.
  - Master processing: DC blocker, optional low cut / BASS+, peak limiter, soft clip.
- **What is missing:**
  - **No tremolo or autopan effect.** The only amplitude modulation is the per-voice LFO→AMP (voice.c:726-727) and the matrix's per-block PAN destination (mod.c:24-25).
  - **No wah or envelope-follower filter.**
  - **No compressor** (the limiter is the only dynamics stage).
  - **No tape/analog delay.** The delay has a fixed read tap and is not modulated.
- **The phaser exists twice:** a mono per-track INSERT (fx.c:728-748) and a stereo master version (perform.c:695-739). Both are 4 first-order allpass stages with a 33-entry Q14 coefficient table (perform.c:696-700).
- **The delay is tempo-synced** (fx.c:216-240): BPM or a measured external MIDI clock (midi_clock.c:33-66), 13 note values including dotted. It uses a 64 Ki-sample int16 line in the pool (fx.c:5-7).
- **Physical modelling:**
  - A DaisySP port: a 12-mode SVF modal bank (phys_dsp.c:213-454), a membrane variant, an extended Karplus-Strong string with a dispersion allpass (phys_dsp.c:456-711), and Rings-style sympathetic strings (phys_symp.c).
  - It is expensive: **~13 % of the device per voice** for MODAL (tests/phys_test.c:18).
  - Its per-block coefficient code uses **64-bit divisions** (for example phys_dsp.c:165, :168, :275). Frodhes forbids those (frodhes: docs/RULES.md "No 64-bit division").
  - It is a good *reference* for a Rhodes tine but not a drop-in.
- **Cost scale used here:** Felucca's tests convert host instruction counts to device load at **"1.7 % per 100 instructions per sample"** (tests/drum_test.c:28, tests/reverb_test.c:20-22). Felucca's "%" is the share of real time (render µs over the duration of a 128-frame half, audio.c:128).
  - The Frodhes limit (< 2.9 ms per 256 frames) is **50 % of real time**.
  - 1 % of real time ≈ **58 µs per 256-frame block**.

## Effects chain overview

Per block of CTL = 32 samples (audio.c:116-121 calls `audio_block` per CTL inside each 128-frame half; HALF_FRAMES = 128, core.h:15):

```
 per part (x4)                                                         fx.c:877-940 (mix_part)
 voices -> DIST -> INSERT -> SLICER -> mute -> LEVEL/PAN --------------> mix_l / mix_r (stereo dry)
   fx.c:906  fx.c:908   slicer.c   perform.c:372   fx.c:915-933   \
                                                                    +-> send_c (CHO send, mono)
                                                                    +-> send_d (DLY send, mono)
                                                                    +-> send_r (REV send, mono)
 mix_block (fx.c:1031-1084)
   perf_pre: THROW knob adds the dry mix to the DLY/REV sends (perform.c:396-409)
   fx_buses (fx.c:558-602):  CHORUS(send_c) + DELAY(send_d) + REVERB(send_r)  -> wet[] (mono)
   rev_side_mix: HALL's L-R side added to L, subtracted from R (fx.c:606-613, 1069-1070)
   (mix + wet) * MASTER (fx.c:963-964 / 1078-1079)
   perf_block (FX layer, only while active): [REPEAT|REVERSE|TAPE|FREEZE|OCT] -> LPF -> HPF -> CRUSH
                                              -> FLANGER -> PHASER                 (perform.c:43, 742-803)
   master_out: DC block -> [LOWCUT | BASS+] -> peak limiter -> softclip   (fx.c:187-214)
 audio_block: USB tap -> (USB-fixed DAC scale) -> metronome click -> << 7 to 24-bit (audio.c:27-44)
```

- **Wet/dry:**
  - The buses are pure wet, fed by per-track sends of 0..127 × 258 in Q15 (fx.c:917, 926-930).
  - The INSERT has a MIX knob (fx.c:653, 719).
  - FX-layer stages crossfade with `pf_mix` (perform.c:432-435).
- **Mono/stereo:**
  - The dry mix is stereo. The bus wet is mono and is added equally to L and R (fx.c:963-964).
  - Only HALL adds a stereo side signal (fx.c:59-61).
  - The FX-layer FLANGER and PHASER are stereo, with the right channel offset by 90° of the sweep (perform.c:687, 728).
- **Smoothing:**
  - Coefficients are computed once per block (fx.c:561-565; perform.c:349-353, 723-728).
  - Wet shares and mutes glide per sample at `SL_SLOPE` = 32768/128, i.e. 2.9 ms end to end (slicer.c:22-24).
  - The throw sends glide at `THR_SLOPE` 64/sample (11.6 ms; perform.c:77).
  - Exception: the delay time is not smoothed (see Delay).
- **ISR structure:** `fm1_alnk0_irq` renders each 128-frame half in CTL blocks and measures the time it took. It sheds a voice after two halves in a row above 85 % (audio.c:46-62, 97-141).

## Effect: DELAY (bus, tempo-synced)

- **Code:** fx.c:5-7 (buffer), 216-240 (time), 582-588 (DSP), 562-568 (parameters).
- **Algorithm** (per sample, mono):
  ```
  x  = dly_buf[(w - dl) & 0xFFFF]                 // fixed integer tap, no interpolation
  lp += mulq15(x - lp, col)                       // one-pole LP in the feedback ("COLOR")
  dly_buf[w & 0xFFFF] = clamp16((in >> 1) + mulq15(lp, fb))
  w++ ; wet += mulq15(x << 1, dmix)
  ```
- **Formats:** int16 line holding half the level (headroom, `>>1` in and `<<1` out); Q15 coefficients.
- **Parameters** (params.c:191-194):

  | Parameter | Range (default) | Mapping |
  |---|---|---|
  | TIME `G_DTIME` | enum of 13 (default 1/8) | `N_DTIME` = 1/4 1/8 1/16 1/32 8T 16T 1/2 1/1 2BAR 4BAR 1/8D 1/16D 1/4D (params.c:16-17) |
  | FDBK `G_DFDBK` | 0..120 (60) | `fb = v*230`, i.e. Q15 0..0.84 |
  | COLR `G_DCOLOR` | 0..127 (70) | `col = 2000 + v*240`, Q15 0.061..0.99. With fc ≈ −fs·ln(1−k)/2π, that is ~440 Hz to fully open (**ESTIMATE**) |
  | MIX `G_DMIX` | 0..127 (90) | `dmix = v*258` |

  ECHO THROW raises the feedback towards `THR_FB` = 0.7 while held (fx.c:566-567, perform.c:78).
- **Tempo sync:**
  - `beat_samples()` = `FS*60/BPM`, or `midi_beat_samples` when CLK is external and a tempo has been measured (fx.c:219-222).
  - The external tempo is measured every 6 clocks (a 1/16): `new_beat = FS*dt_ms/250`, accepted only for 62..375 ms (midi_clock.c:40-66).
  - `div_samples()` uses `DIV_DEN = {1,2,4,8,3,6}` and doubles for 1/2..4BAR (fx.c:217, 223-227).
  - Dotted values: `(beat*3) >> {2,3,1}` (fx.c:234-238).
  - The result is clamped to 16..65535 samples (fx.c:239). The longest time is 1.486 s, so 1/4D clamps at ≤ 60 BPM (fx.c:232-233).
- **Smoothing caveat:** `dl` is recomputed every block (fx.c:561) and used directly (fx.c:583). A TIME or tempo change jumps the read tap, which clicks or glitches. Frodhes should glide or crossfade.
- **Memory:** `dly_buf[65536]` int16 = **128 KiB in `.pool`** (fx.c:5-7). State is about 12 B.
- **Cost:** about 15–20 host instructions/sample ≈ 0.3 % of real time (**ESTIMATE**, from the op count above).

## Effect: CHORUS (bus)

- **Code:** fx.c:6, 8, 565, 571-581.
- **Algorithm** (per sample, mono, wet only):
  ```
  cho_buf[w & 2047] = clamp16(in >> 1)
  ph += cinc                                     // cinc = LFO_INC[CRATE]/CTL (per-sample phase)
  r  = (400 << 8) + (((osc_sine(ph)+32768) * cdepth) >> 8)   // delay in Q8 samples
  y  = lerp(buf[w - r>>8], buf[w - r>>8 - 1], r & 255) << 1
  ```
- **Parameters:** CRT 0..127 (40) on the F_LFOHZ scale 0.05..40 Hz (params.c:197, gen_tables.py:45-47); CDP 0..127 (60), `cdepth = v*6` (fx.c:564).
- **Delay range:** 400 samples (9.07 ms) up to +762 samples at full depth, i.e. 9.1–26.4 ms (**my arithmetic**, assuming `osc_sine` returns ±32768; that function lives in the missing submodule). This disagrees with the comment "5..15 ms" (fx.c:571).
- **Design:** one tap, no feedback, mono.
- **Memory:** `cho_buf[2048]` int16 = **4 KiB in `.pool`** (fx.c:6, 8).
- **Cost:** about 20 instructions/sample ≈ 0.35 % (**ESTIMATE**).

## Effect: REVERB (bus; `G_RTYPE` 0 ROOM, 1 SPRING, 2 HALL; default HALL, params.c:217)

**Shared memory:**
- `rev_comb[1116+1188+1277+1356]` int16 = 4937 samples = 9874 B in `.pool` (fx.c:11).
- `rev_u` (union): int16 `ap[997]` or int32 `sp[498]`, about 1994 B in `.pool` (fx.c:12-16).
- HALL's state struct `hl` is also in `.pool` (fx.c:78-89). **ESTIMATE** of its size with CTL = 32: about 0.7 KiB.
- Total ≈ **12.5 KiB of pool**.

**Parameters:** SIZE `G_RSIZE` 0..127 (90) and DAMP `G_RDAMP` 0..127 (60) (params.c:195-196).

**Model switching:** the old model's block fades out linearly over the block, then the buffers are cleared and the new model starts from silence (fx.c:537-555, 594-595, rev_clear fx.c:492-505).

### ROOM (fx.c:242-272): 4 damped combs + 2 allpasses, Freeverb-style, mono

```
in = mulq15(send, 2580)                        // 0.0787
for k in 0..3: o = comb_k[i]; lp_k = o + mulq15(lp_k - o, RDAMP*200)
               comb_k[i] = clamp16(in + mulq15(lp_k, 25000 + RSIZE*50)); a += o
for k in 0..1: o = ap_k[i]; ap_k[i] = clamp16(a + o/2); a = o - a     // Freeverb allpass, g = 0.5
out += a
```

- Comb lengths: {1116, 1188, 1277, 1356}. Allpass lengths: {556, 441} (fx.c:9-10).
- Feedback is Q15 0.763..0.957. The damping LP coefficient runs from 0 to 0.775.
- Cost: see the cost note below. The static loop metric is 218 (tests/target_budget.txt).

### SPRING (fx.c:29-44, 274-316): a single-spring loop with dispersion (after Välimäki, Parker and Abel)

```
x  = mulq15(send, 2580) + towards0(lp(loopReturn, kl) * g)    // kl = 26000 - DAMP*160 (Q15), g = 19661 + SIZE*85 (0.6..0.93)
x -= lowcut(x)       // one-pole HP >>6 (~110 Hz), remainder kept (error feedback)
10x stretched allpass  H(z) = (a + z^-4)/(1 + a z^-4),  a = SP_A = 2867 (Q12, 0.7), int32 states, rounding towards 0
line[w] = clamp16(x)                                          // loop length L = 1323 + SIZE*1323/128 samples (30..60 ms), Q8, glides 1 sample/block
out += 4*lerp(tap at L/2 + wobble) + 2*line[w - 3L/4]         // wobble: sine at 2*LFO_INC[24] per block, ±1.5 samples
```

- Constants: SP_LEN 4096 (masked), SP_N 10, SP_A 2867 (fx.c:39-43).
- Rounding: loop products are rounded towards zero so the tail never sits on a limit cycle or offset (fx.c:298, 306-308).
- Tested: RT60 is 0.15..1 s at SIZE 0 and 2..6 s at 127; the chirp rises 1→5 kHz by ≥ 2 ms (tests/reverb_test.c:9-15, 230-249).
- Static loop metric: 126.

### HALL (fx.c:46-90, 318-489): an 8-line FDN at 22.05 kHz, stereo out

1. **Input:** the send is decimated with a 1-2-1 filter (fx.c:413), scaled by 2580, then low-cut ~110 Hz (`>>5` at half rate, fx.c:416-419).
2. **Diffusers:** 2 Schroeder allpasses, lengths {131, 307}, gains Q14 {11469, 10240} = 0.7 and 0.625 (fx.c:73-74, 344-352).
3. **Lines:** 8 lines, lengths {467, 509, 547, 593, 631, 673, 709, 743} at 22.05 kHz, i.e. 21..34 ms (fx.c:72), each with one mirror sample (fx.c:448).
   - Lines 1, 2, 4 and 7 are read through slow sines: ±`HL_MOD` = 8 samples, 0.37 / 0.74 Hz, linear interpolation (fx.c:67, 402, 433-439).
   - Lines 0, 3, 5 and 6 (mask 0x69) pass a one-pole LP, `HL_KD(d) = 32767 - d*180` in Q15 (fx.c:68-69), with remainder feedback (fx.c:370-387).
4. **Line gains:**
   - Formula: `g = 2^(-D·59.2/65536·2^(-SIZE/30))`, capped at 0.99, times 1/√7 (6193 Q15). That gives RT60 = 0.5 s × 2^(SIZE/30): 0.5 s at 0, 4 s at 90, 9 s at 127 (fx.c:56-57, 330-341).
   - `exp2_neg` is a cubic for 2^-x (fx.c:321-329). The gains are recomputed only when SIZE changes (fx.c:410-411).
5. **Feedback matrix:** an 8×8 Paley conference matrix (order 8, ±1, zero diagonal), built from the quadratic character mod 7 using adds only (fx.c:456-469).
6. **Outputs:**
   - L = y0+y3+y4−y7, R = y1+y2+y5+y6 (fx.c:454-455).
   - The mono wet gets (L+R)·4 and the side gets (L−R)·4, linearly upsampled to 44.1 kHz (fx.c:478-486).
   - The side is added to the dry L and subtracted from R (fx.c:606-613).
7. **Rounding:** quiet lines round towards zero so the tail ends in exact silence (fx.c:61-63, 353-367, `HL_LOUD` 32).
8. **Structural constraints:** CTL must be even, and HL_NC = CTL/2 ≤ 131 (fx.c:66, 77). Frodhes would have to call it in 32-frame sub-blocks.

**Measured cost:** HALL ≤ 1.3 × ROOM host instructions/sample, and the whole bus stage within +2 % of device CPU of ROOM's (tests/reverb_test.c:20-22, 811-831). Absolute numbers are not stored in the repo. My **ESTIMATE**: ROOM ≈ 80 host instr/sample (6 delay lines × ~12 instructions) ≈ 1.4 %; SPRING and HALL ≤ 105 ≈ 1.8 % of real time.

## Effect: PHASER

### (a) FX-layer PHASER, stereo, tempo-locked (perform.c:30-34, 75-76, 643-739)

```
per block: q = sweep phase at the block's middle; a_L = ph_coef(q), a_R = ph_coef(q - 90°)
  ph_coef: t = triangle(q) (0..65534); a = lerp(PH_A[t>>11], PH_A[(t>>11)+1], t & 2047)   // Q14
per sample, per side:
  xs = clamp((x+2)>>2, ±16383); u = xs + round(fb*PH_FB)          // PH_FB = 13107 (0.4)
  4x: y = clamp(px + ((a*(u - py) + 8192) >> 14), ±65535); px = u; py = y; u = y   // 1st-order allpass, y = a(u - y1) + u1
  fb = clamp(y, ±32767);  out = pf_mix(x, (xs + y)*1.8, wet)     // (x + ap)/2 * 0.9, *4 undoes the >>2
```

- **PH_A** (Q14, 33 entries): a = (g−1)/(g+1), g = tan(π f/fs), f = 150 Hz·2^(5i/32), so 150 Hz..4.8 kHz:
  `-16038 -15998 -15955 -15906 -15853 -15793 -15727 -15653 -15572 -15481 -15381 -15270 -15147 -15012 -14862 -14696 -14514 -14313 -14092 -13849 -13582 -13290 -12970 -12621 -12240 -11825 -11375 -10886 -10356 -9784 -9166 -8500 -7783` (perform.c:695-700).
- **Rate:** one triangle cycle per 8 sixteenths, i.e. half a bar, locked to the transport (`perf_lfo(8u,…)`, perform.c:645-650, 726). There is no free-rate knob. The level comes from KNOB 4 DEPTH (perform.c:658).
- **Memory:** state only, `px/py[2][4]` plus fb, about 72 B, in the `pf` struct (.bss) (perform.c:148).
- **Cost:** static loop metric 448. My **ESTIMATE**: about 80–90 host instructions/sample for stereo ≈ 1.5 % of real time.

### (b) INSERT PHASR, mono, free rate (fx.c:624-625, 726-748)

- Same allpass form.
- Rate: `inc = LFO_INC[A]/CTL`, 0.05..40 Hz.
- Depth: the triangle is scaled around the centre, q = 32768 + (tri−32768)·dep/127. The centre sits near PH_A[16], about 850 Hz. Full depth sweeps 150 Hz..4.8 kHz.
- Feedback: `c*180`, 0..0.7 Q15.
- Input is scaled `>>3` and output `<<2`. A ~14 Hz DC blocker follows. Wet = (dry + ap)/2, then MIX.
- State is in the pool inside `ins_t` (580 B per track, fx.c:641-651).
- Static loop metric 230 (shared with the flanger and chorus inserts).

**Closest classic match:** a 4-stage, one-feedback phaser is the Phase 90 / Small Stone family, so it suits a Rhodes as-is.

## Effect: FLANGER / CHORUS inserts and the FX-layer FLANGER

- **INSERT FLANG/CHOR** (fx.c:626-628, 750-773):
  - 256-sample int16 line per track at 1/4 level (`IL_LEN`, fx.c:639).
  - CHOR: delay = 140 samples ± 50·dep·sine (3.2 ± 2.3 ms), feedback 0..0.4 (`c*103`).
  - FLANG: delay = 11 + 209·(tri²)·dep (0.25..5 ms), feedback 0..0.85 (`c*219`), through softclip.
  - Linear interpolation in Q15. Wet = (dry + delayed)/2 with a DC blocker.
- **FX-layer FLANGER** (perform.c:25-29, 71-74, 660-693):
  - Stereo, 22..353 samples (0.5–8 ms), squared triangle, one cycle per bar (16 sixteenths), right channel 90° behind.
  - Feedback 0.5 through softclip. Output (x + d)/2 × 0.85.
  - `fl_buf[356][2]` int16 = **1424 B in .bss (RAM, not pool**; perform.c:151 has no section attribute).
  - Static metric 368.

## Effect: DRIVE / DIST / INSERT drives

- **Track DIST** (fx.c:92-114), per sample:
  ```
  hp += (x - hp + 64) >> 7                         // ~55 Hz low cut before the clipper
  x  = clamp(x - hp, ±230000)
  y  = softclip((((x>>2) * g) >> 10) + 2400) - softclip(2400)   // asymmetric: bias 2400 = even harmonics
  lp1 += mulq15(y - lp1, k); lp2 += mulq15(lp1 - lp2, k)          // 2-pole tone LP, closes with drive
  out = mulq15(lp2, mk)
  ```
  - `g = 4096 + d²·2` (Q12, 1× .. ~9×), `k = 32000 − 95d`, `mk = 30000 − 120d`. DST is 0..127 (params.c:117).
  - When d = 0 it is bypassed and keeps its state, so turning it on does not click (fx.c:99-100).
  - State per track: `dist_hp`, `dist_lp1`, `dist_lp2`.
  - **ESTIMATE:** about 20 instructions/sample.
- **INSERT SOFT/HARD/FOLD/FUZZ** (fx.c:618-621, 660-721):
  - Signal flow: ~27 Hz low cut (Q8), then DRIVE `g = 4096 + a²·3` (1..12.8×), then the shape, then TONE, LEVEL and a DC blocker (~14 Hz).
  - Shapes: SOFT = softclip; HARD = clamp ±24000; FOLD = triangle fold at ±16384 ×1.5; FUZZ = hard top at 20000 with a halved softclip bottom.
  - TONE is two TPT one-poles with `G = g/(1+g)` from `SVF_G` (fx.c:655-659).
  - LEVEL comes from the `LEVEL_Q12` table: (v−112)/2 dB (gen_tables.py:52-54).
- **CRUSH:** bits 1..16; sample hold 64..1 samples from `INS_HOLD` (fx.c:640, 676-677, 694-700).

## Effect: tremolo / autopan

**None as an effect.** What exists:
- Per-voice LFO→AMP: `amp1 *= 1 − lfo·LD_AMP` (voice.c:726-727).
- The modulation matrix's per-block PAN destination (mod.c:24-25, 54).

Neither is a stereo autopan with per-sample gain ramps. The pan law in fx.c is linear: `gl = 4096 − pan·64` (fx.c:916). This has to be built from scratch (see Recommendations).

## Effect: master dynamics and EQ (fx.c:116-214)

- **DC blocker:** ~2 Hz leaky integrator in Q6 with error feedback (fx.c:139-150).
- **LOWCUT / BASS+:**
  - Two one-pole HPs, `>>6` (~110 Hz) or `>>5` (~220 Hz) (fx.c:152-159, 192-199).
  - BASS+ adds clipped low-band harmonics: a 4-pole LP with coefficient 692, a trapezoid clip at the envelope, a band-pass, ×1.5 (fx.c:161-185).
- **Limiter:**
  - `LIM_T` = 18000. Attack: `env += (a−env)>>2` per sample (~0.1 ms). Release: `−((env−T)>>12)−1` per sample (~150 ms).
  - Gain = `(T<<15)/env`: a **32-bit division per sample while limiting**. It is applied as `((x>>4)·g)>>11`, then softclip (fx.c:116-120, 200-213).
- **MASTER pot:** square law, `(k10²)>>8` (fx.c:127).

## FX-layer extras (perform.c), briefly

- **REPEAT / REVERSE / TAPE STOP / FREEZE:** these borrow the slicer's 32 KB buffer as an 8192-frame stereo loop at 22.05 kHz (perform.c:35-37, 60-65, 437-627).
- **OCT UP/DN:** a rotating two-tap delay pitch shifter with shimmer feedback 0..0.82 (perform.c:18-24, 497-542).
- **LPF/HPF:** a ZDF SVF with k = 1, from the table `PF_SVF[64][3]` (Q14 a1 a2 a3; cutoff 30 Hz·2^(i/7)). The coefficients are interpolated per block, the sweep is bar-long, and the filter is `pf_svf` (perform.c:103-118, 328-354, 629-636).
- **THROW / REV THROW / ECHO THROW:** these push the sends (perform.c:395-429).

## Physical-modelling DSP blocks (phys_dsp.c MIT, phys_symp.c MIT, eng_phys.c GPL)

**Number formats** (phys_dsp.c:35-49):

| Quantity | Format |
|---|---|
| Signals between stages | Q20 |
| Modal exciter | Q24 |
| Mode states | Q22 (clamped at ±64 per block) |
| Frequencies | cycles/sample, Q32 |
| SVF `g` | tan(πf), Q28 |
| `r+g` | Q28 |
| `g·h` | Q30 |

- All products are `px_m` = 32×32→64-bit then shift (phys_dsp.c:71).
- Coefficients are recomputed per block of 32 samples (phys_dsp.c:50).
- Math helpers: `px_sin` (quarter-wave odd polynomial, ~4e-6, :83-99), `px_exp2` (degree-7 polynomial, :101-118), `px_fasttan` (:120-127), `px_atan` (:129-139), `px_isqrt64` (:141-156).

### Blocks

1. **Modal resonator bank (DaisySP Resonator + ResonatorSvf), MODAL** (phys_dsp.c:158-172, 213-337, 400-454):
   - Topology:
     - The exciter is a low-pass SVF (q 1.5 struck / 0.7 bowed). Its cutoff is `f0·2^((b(2−b)−0.5)·60/12)` (:256-260).
     - Strike: one impulse with amplitude `(0.12+0.08·accent)(1−d/2)·2^(2cut²)/cut` (:271-277).
     - Bowed: "Dust" random impulses (:263-270).
   - Up to `PX_NMODE` = 12 band-pass SVF modes (DaisySP has 24) (:63).
     - Frequencies come from `stretch`, driven by STRUCTURE through `px_stiff` (:234-246, 309-329).
     - Q starts at `500·2^(d·79.7/6)` and is multiplied by `ql` from mode to mode (:281-288).
     - Amplitudes follow `cos(2π·pos·i)·(1−2f)` (:314-322).
   - Per sample per mode: `t = gh·(x − rpg·s1 − s2); v = s1+t; s1 = v+t; t = g·v; s2 += 2t; acc += a·v`. That is 4 64-bit multiplies (:443-451).
   - Coefficient guarantee: `h` is rounded down and `1/q` rounded up, so the quantised filter is never less damped than the exact one (:39-41, 162-172).
   - **Cost:** "~13 % per voice" measured on the device for MODAL struck (tests/phys_test.c:16-18). Polyphony is 3 per part (eng_phys.c:36, 45). Static metrics: px_modal_run 192, px_modal_block 111 (tests/target_budget.txt).
   - **Hazard: 64-bit divisions** in `px_svf_coef` (:165, :168), the strike (:275), Dust (:268) and the membrane (:386). Felucca's toolchain links them. Frodhes must not use them.
2. **Membrane, MEMB** (phys_dsp.c:339-398):
   - The same bank with **explicit mode-ratio tables**: `PX_MEMB_IDEAL` (Bessel zeros) and `PX_MEMB_LOADED`, 10 entries each, in Q16 (:346-349).
   - Blended by HARM. Per-mode amplitudes come from strike position weights `w[m]`, and the level is scaled by 1/ratio² (:372-388).
   - A pitch bend after the strike decays ×0.98 per block (:360-367).
3. **Extended Karplus-Strong string, STRNG** (phys_dsp.c:456-711):
   - A 512-sample Q20 delay line (DaisySP: 1024), resampled below 88 Hz (:63-65, 537-546).
   - Hermite read (:587-596).
   - A dispersion allpass on a 128-sample line, with gain `−0.618·nl/(0.15+nl)` (:583, 653-663).
   - A curved-bridge nonlinearity (:668-675).
   - A DcBlock with error feedback (:678-685) and a OnePole damping filter (`G = sin/(sin+cos)`, :566-569, 686-690).
   - Damping compensation (:570-572).
   - Exciter: a burst one period long through a double-sampled Chamberlin SVF, with a pluck-position comb (:598-631).
   - Static metrics: px_string_run 264, px_string_excite 171.
   - **64-bit divisions** at :492, :561, :568, :571, :583.
4. **Sympathetic strings, SYMP, after Rings** (phys_symp.c:23-156):
   - 3 extra strings, each a 256-sample int16 line (Q12) at half rate.
   - A 3-tap combined FIR, loop gain and interpolation (`h[k][0..2]`, Q24).
   - Decay RT60 = `0.07 s·2^(8d(2−d))`. They are driven by the main string through a DC blocker (:59-104, 111-156).
   - Coefficients are recomputed only when an input changes (:66-74). Static metric px_symp_run 252.
5. **The engine wrapper** (eng_phys.c):
   - Per-model output gain `PHYS_GAIN` (:48).
   - Soft knee above 24000 (`a = 24000 + softclip((a−24000)·2)/2`, :211-216).
   - Parameters are mapped to Q16: ×516 (0..127 → 0..1) (:168-171).
   - The state union per voice is sized by SYMP (:50-59).

### Reusability for a Rhodes tine

- **Modal bank:**
  - The **SVF band-pass mode** is a sound, unconditionally stable resonator in fixed point, with a damping-safe quantisation trick (:39-41).
  - Its frequency and Q *generator*, however, is DaisySP's STRUCTURE/BRIGHTNESS/DAMPING macro (stiffness-stretched partials, geometric Q). There are no per-key partial ratios and no independent per-partial decays.
  - For a Rhodes we want 3–6 partials per key: tine fundamental, tine 2nd mode (≈ 6–7× at low keys), tonebar, and pickup harmonics. Each needs its own ratio, decay and amplitude, read from a per-key table.
  - The MEMB code shows the explicit-ratio-table pattern (:346-388).
  - Cost is the blocker. At ~13 % of real time per voice for 12 modes, 8 voices would take ~104 %.
  - **Recommendation:** keep the *idea*. Use a cheaper 2-multiply resonator per partial with exponential decay (a coupled-form/"magic circle" oscillator, or `y = 2r·cos(ω)·y1 − r²·y2`). Compute its coefficients at note-on and on damper change from host-generated tables, so there are **no runtime divisions**.
- **Exciter:**
  - The modal "strike" (an impulse into a velocity- and brightness-dependent LP SVF, :256-277) is a reasonable first hammer model.
  - A Rhodes hammer is better as a short raised-cosine force pulse whose width shrinks with velocity (neoprene stiffening). That is a from-scratch Q15 table lookup.
- **Pickup:** none exists. Felucca has only an output soft knee (eng_phys.c:211-216). The Rhodes electromagnetic pickup nonlinearity (DAFx17, see 01-dafx17.md) has to be written from scratch, for example as a rational or polynomial in tine displacement evaluated in Q15 with a table.
- **String/KS:** not needed for a tine. The dispersion allpass and the DcBlock with error feedback (phys_dsp.c:678-685) are reusable utilities.
- **Sympathetic strings:** not relevant to a Rhodes.
- **Utilities worth copying** (MIT, keep the notice): `px_sin`, `px_exp2`, `px_atan`, the error-feedback DC blocker, and xorshift.

## Frodhes recommendations: a reface CP–style chain

Scope from the coordinator: mimic the Yamaha reface CP's effects order. **The Yamaha pages could not be fetched** (both URLs returned HTTP 403), so the description below is the coordinator's, not verified here:

DRIVE (one knob) → TREMOLO/WAH (switch; DEPTH, RATE) → CHORUS/PHASER (switch; DEPTH, SPEED) → D.DELAY/A.DELAY (switch; DEPTH, TIME; plus optional BPM sync) → REVERB (one knob for time and amount).

**Conventions:**
- Mono until the tremolo. Stereo from the autopan onward.
- Run each block per 16- or 32-frame sub-block: coefficients per sub-block, gains ramped per sample (Felucca's SL_SLOPE pattern, slicer.c:22-24).
- All memory below is in `.pool` unless noted. The pool is 344064 B and RAM 98304 B (frodhes: tools/build.py:219-220, firmware/app.ld:15-16).
- Costs are **ESTIMATES** in host instructions/sample, converted at 1.7 %/100 (tests/drum_test.c:28). 1 % of real time ≈ 58 µs per 256 frames.

### 1. DRIVE (one AMOUNT knob, matched to the voice)

- **Port** `track_dist` (fx.c:96-114) as-is (GPL). Replace `softclip` with our own Q15 tanh table: 257 entries, linear interpolation, in flash.
- **Voice matching:** add a per-voice-type table of {bias (2400 by default), gain curve scale, tone `k` endpoints, make-up}. For example, Rd: more bias (even harmonics, "bark"); Wr: harder, odd-ish; CP: a light tone.
- **Knob mapping:** d = 0..127. `g = 4096 + d²·2·scale_voice`, `k` and `mk` as in Felucca. Bypass at 0 and keep the state.
- **Memory:** 12 B (RAM). **Cost:** ~20 instructions/sample ≈ **0.35 %**.

### 2. TREMOLO / WAH (switch; DEPTH, RATE)

**TREMOLO** (from scratch; there is no Felucca code):
- One LFO phase (uint32, `inc = Hz·2³²/fs`, rate ≈ 0.5..12 Hz on an exponential table like `LFO_INC`, gen_tables.py:45-47). Evaluate it per sub-block from a 256-entry Q15 sine table and interpolate the gains linearly per sample.
- **Autopan** (Rd voices, the Suitcase "vibrato"): equal-power `gL = cos(θ)`, `gR = sin(θ)`, with θ = π/4 + depth·sin(φ)·π/4. Two multiplies per sample.
- **Amplitude tremolo** (Wr/CP style): `g = 1 − depth·(1+sin φ)/2`, applied to both channels.
- **Memory:** about 24 B (RAM). **Cost:** ~10 instructions/sample ≈ **0.2 %**.

**WAH, touch/auto-wah** (from scratch, assembled from Felucca parts):
- Envelope follower on |x|: attack `+= (a−e)>>3`, release `−= (e>>11)+1`. This is the pattern of fx.c:173-177 and 203-206.
- `cut_idx = base + DEPTH·e`, mapped onto a 64-row cutoff table from 300 Hz to 2.5 kHz.
- Resonant ZDF SVF: reuse `pf_svf` (perform.c:629-636, GPL) with a **new host-generated table** `a1, a2, a3` (Q14) for **k ≈ 0.25–0.35** (Q ≈ 3–4), because `PF_SVF` is k = 1 only (perform.c:103-104).
- Output a band-pass/low-pass blend, for example `0.7·bp + 0.3·lp`. Interpolate the coefficients between rows per sub-block, as perform.c:349-353 does.
- RATE sets the follower's release (or a slow LFO mix-in). DEPTH sets the sweep span.
- **Memory:** table 64×3 int16 = 384 B (flash); state about 24 B. **Cost:** ~25–30 instructions/sample ≈ **0.5 %**.

### 3. CHORUS / PHASER (switch; DEPTH, SPEED)

**PHASER:**
- **Port** the stereo `ph_side` / `perf_phaser` (perform.c:695-739) with `PH_A` (perform.c:696-700) as-is (GPL).
- Replace the tempo-locked `perf_lfo` with a free SPEED phase increment, as the INSERT does: `LFO_INC[x]/CTL` (fx.c:726). Keep the right channel 90° behind (perform.c:728).
- DEPTH sets the sweep span around ~850 Hz, as the INSERT does (fx.c:729-730). Optionally DEPTH also scales the feedback (0.4 fixed now, perform.c:76; the INSERT allows 0..0.7, fx.c:731).
- **Memory:** about 72 B (RAM). **Cost:** ~85 instructions/sample stereo ≈ **1.5 %**.

**CHORUS** (stereo, port and extend):
- Use the bus chorus core (fx.c:571-580), but with two read taps (L, R) driven by the same LFO 90° or 180° apart (Juno-style).
- Delay 5–12 ms at depth 1, i.e. ~220..530 samples. A line of **1024 int16 = 2 KiB in the pool** is enough. Felucca's own line is 2048 samples, 4 KiB (fx.c:6).
- Keep the dry signal in the output (`out = dry·(1−m) + tap·m`, with m ≈ 0.5 at full DEPTH).
- **Cost:** ~30 instructions/sample ≈ **0.5 %**.

### 4. D.DELAY / A.DELAY (switch; DEPTH = feedback and level, TIME = ms or a note value with SYNC)

**Shared core:** port `fx_buses`' delay (fx.c:582-588). Sizing options:
- Keep `DLY_LEN` 65536 int16 = 1.486 s, **128 KiB of pool**.
- Or trim to 1 s = 44100 samples, then round up to a power of two: still 64 Ki (128 KiB) masked, or 48000 samples with a compare-wrap at 94 KiB.

**D.DELAY:**
- A clean tap with the COLOR one-pole LP in the feedback.
- **Fix the time jump:** glide `dl` (Q8) towards its target by ≤ 1 sample per sample, or crossfade two taps over 32 samples when the change is large.

**A.DELAY (tape/BBD):**
- Fractional read with linear interpolation, as in fx.c:574-579.
- `dl_eff = dl + wow + flutter`: wow is a 0.5–1 Hz sine of ±0.3 % of `dl`; flutter is 6–8 Hz at ±0.05 %, plus a little filtered noise.
- TIME changes **slew** (pitch glide, as with tape) with a one-pole on `dl` (~100 ms).
- Feedback path: LP (~2.5 kHz) → `softclip` (tape saturation) → the 55 Hz HP of fx.c:107. Optionally store at 22.05 kHz to halve memory, as HALL does (fx.c:47-50).

**Tempo sync** (optional, global BPM): port `beat_samples` / `div_samples` / `delay_samples` (fx.c:216-240) with `N_DTIME` (params.c:16-17). If MIDI clock in is wanted, port the tempo measurement of `midi_clock_pulse` (midi_clock.c:36-66). With SYNC on, the TIME knob selects among the 13 values. FS·60/BPM is a 32-bit division per block, which is fine.

**Knobs:** DEPTH → feedback 0..0.8 (`v·~206` Q15, below Felucca's 0.84 cap, fx.c:562) and wet level together.

**Memory:** 94–128 KiB of pool, about 20 B of state. **Cost:** D ≈ 20, A ≈ 40 instructions/sample, i.e. **0.35 % / 0.7 %**.

### 5. REVERB (one knob: time and amount)

- **Port** HALL (fx.c:46-90, 318-489, 606-613) as-is (GPL). It is stereo, dense, has no metallic ringing (tests/reverb_test.c:23-27), and fits the reface's plate/hall-like reverb.
- Optionally offer SPRING (fx.c:274-316) as a "Twin amp" variant. It shares the same buffers.
- **One knob:** v = 0..127 → `SIZE = 40 + v·70/127` (RT60 ≈ 1.25..~5 s, fx.c:56-57) and `send = v·258` (Q15), with DAMP fixed at ~60. `hall_gains` already runs only when SIZE changes (fx.c:410-411). Rate-limit the knob so it does not run every block while turning.
- Frodhes changes: call it per 32-frame sub-block (HL_NC = CTL/2 ≤ 131, fx.c:77), and supply `osc_sine`, `mulq15` and `clamp`.
- **Memory:** **~12.5 KiB of pool** (fx.c:11-15, 78-89). **Cost:** ≤ 1.3 × ROOM (tests/reverb_test.c:824) ≈ ~105 instructions/sample ≈ **1.8 %**.

### Output stage

- **Port** `master_out` (fx.c:144-214): DC block, limiter and softclip. Skip LOWCUT/BASS+ unless the FM-1 speaker needs it (BASS+ was written for the small speaker, fx.c:135-136).
- **Memory:** about 40 B. **Cost:** ~25 instructions/sample ≈ **0.4 %**.

### Total budget (ESTIMATE)

| Block | Memory | % real time | µs / 256 frames |
|---|---|---|---|
| Drive | 12 B RAM | 0.35 | 20 |
| Tremolo **or** wah (worst: wah) | 24 B RAM + 384 B flash | 0.5 | 29 |
| Chorus **or** phaser (worst: phaser) | 2 KiB pool (chorus) / 72 B RAM | 1.5 | 87 |
| D/A delay (worst: A) | 94–128 KiB pool | 0.7 | 41 |
| Reverb HALL | 12.5 KiB pool | 1.8 | 105 |
| Master (DC, limiter, clip) | 40 B RAM | 0.4 | 23 |
| **Effects chain total** | **~109–143 KiB pool, < 0.5 KiB RAM** | **≈ 5.3 %** | **≈ 0.31 ms** |

**8 Rhodes voices:**
- The target is < 2.9 ms per 256 frames = 50 % of real time. After the chain that leaves ~44 % = **~2.55 ms for the voices, i.e. ~5.5 % (~320 µs per 256 frames) per voice**.
- Felucca's 12-SVF-mode voice costs ~13 % (tests/phys_test.c:18), more than twice this.
- A Rhodes voice of about 5 two-multiply resonators, a hammer pulse and a pickup polynomial is roughly 70–90 host instructions/sample, about 1.2–1.5 % per voice (**ESTIMATE**). For 8 voices that is **~10–12 %**.
- **Whole system ≈ 16–18 % of real time ≈ 0.95–1.05 ms per 256 frames.** That leaves roughly 3× headroom under the 2.9 ms limit for more modes, oversampling of the pickup nonlinearity, or tonebar coupling.
- **These ratios are Felucca's, not Frodhes's.** Measure on the device with `fm1_ticks()` (frodhes: docs/RULES.md, "The audio interrupt").

## Gaps

- `firmware/engines/` is empty. The exact definitions of `softclip` (a tanh table, `TANH_Q15`), `mulq15`/`mulq16` rounding, `osc_sine` range and phase, `SVF_G`, and the value of `CTL` (32 per gen_tables.py:6) could not be confirmed from code.
- No absolute CPU numbers for the effects are stored. reverb_test, perform_test and insert_test print them at run time but only assert *relative* limits (tests/reverb_test.c:811-831). `tests/target_budget.txt` holds static loop-instruction metrics, not cycles (tests/target_budget.py:4-11). All per-effect costs above are op-count **ESTIMATES**.
- The "1.7 % per 100 instructions per sample" ratio was derived from PHYS measurements on Felucca's build (tests/drum_test.c:28). Frodhes's compiler flags and code layout may differ.
- The chorus delay range (9.1–26.4 ms by my arithmetic) contradicts the comment "5..15 ms" (fx.c:571). This depends on the unseen `osc_sine` scale.
- The reface CP effect details (types per voice, knob laws, delay maximum time, reverb character) are unverified: the Yamaha pages returned 403.
- How Felucca's toolchain resolves the 64-bit divisions in phys_dsp.c was not found. Felucca's libc.c has no `__udivdi3`. Possibly the clang provides it, or something in the missing submodule does.
